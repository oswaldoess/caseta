# Base de datos

Aquí van los scripts SQL de MySQL 8.4 (Entrega 4):

- `01_esquema.sql`: creación de la base `caseta` y de las tablas de cada servicio.
- `02_datos_prueba.sql`: datos de prueba.
- `03_consultas.sql`: consultas para verificar el funcionamiento.

Cada servicio lee y escribe solo sus propias tablas.
