# Documentación

- `entregas/`: documento de cada entrega semanal.
- `api/openapi.yaml`: especificación OpenAPI 3.0.3 de la API pública. Se puede abrir en https://editor.swagger.io.
- `diagramas/`: arquitectura final (`arquitectura-final.png`), arquitectura de la Entrega 3, modelo de dominio, flujo de registrar una entrada y modelo entidad-relación.
- `postman/`: colección de regresión con casos positivos y negativos, y colección corta para la demo final.
- `evidencias/`: salidas reales de la ejecución de cada entrega (CRUD, errores, colecciones, pruebas, carga y servicio caído).
- `reglas-negocio.md`: reglas de negocio implementadas en la Entrega 6, con dónde se aplica cada una y qué responde la API.
- `pruebas.md`, `seguridad.md`, `defectos.md`: plan y resultados de pruebas, lista de seguridad y defectos corregidos.
- `demo-final.md`: guion de la demo y respuestas para la defensa técnica.
- `retrospectiva.md`: qué salió bien, qué salió mal y qué cambiaríamos.
