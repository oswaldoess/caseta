# Documentación

- `entregas/`: documento de cada entrega semanal.
- `api/openapi.yaml`: especificación OpenAPI 3.0.3 de la API pública. Se puede abrir en https://editor.swagger.io.
- `diagramas/`: diagramas de arquitectura, modelo de dominio y flujo de registrar una entrada.
- `postman/`: colección de Postman (a partir de la Entrega 5).
